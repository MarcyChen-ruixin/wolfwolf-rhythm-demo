# Werewolf Rhythm Demo v0.1.0

First public demo (Windows + macOS packaging).

## Highlights

- Three selectable comedic music tracks
- Three difficulty levels
- Short and HOLD werewolf enemies
- Score, combo, accuracy, Defeated, and Escaped tracking
- Red AGV sweep reward every 50 points
- Offline Windows and macOS builds
- Silent-mode fallback
- Restart and menu navigation

## Download

Windows:

- `WerewolfRhythm-Demo-Windows-v0.1.0.zip`
- SHA-256: see companion `WerewolfRhythm-Demo-Windows-v0.1.0.sha256`

## macOS Builds

- Apple Silicon build (`WerewolfRhythm-Demo-macOS-AppleSilicon-v0.1.0.zip`)
- Intel build (`WerewolfRhythm-Demo-macOS-Intel-v0.1.0.zip`)
- Standalone `.app`
- No Python installation required
- Offline gameplay
- Current builds are ad-hoc signed and not notarized

Companion checksums:

- `WerewolfRhythm-Demo-macOS-AppleSilicon-v0.1.0.sha256`
- `WerewolfRhythm-Demo-macOS-Intel-v0.1.0.sha256`

## Installation

### Windows

1. Download the ZIP.
2. Extract all files.
3. Run `WerewolfRhythmDemo.exe`.

### macOS

1. Download the Apple Silicon or Intel ZIP matching your Mac.
2. Extract the ZIP.
3. Open `Werewolf Rhythm Demo.app`.

## Known limitations

### Windows

- Keyboard controls only
- Unsigned executable may trigger a Windows reputation warning
- No automatic updater
- No online leaderboard
- No controller support

### macOS

- Keyboard-only controls
- No automatic updater
- No Apple notarization in v0.1.0-demo
- Manual Gatekeeper / Privacy & Security approval may be required
- Full GUI behavior still requires testing on physical Mac hardware
- Not a Universal Binary (separate arm64 and x86_64 packages)
- Not Mac App Store, Steam, or Developer ID–notarized
