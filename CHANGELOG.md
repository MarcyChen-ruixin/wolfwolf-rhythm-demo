# Changelog

## 0.1.0-demo

First public Windows demo.

- Three Kevin MacLeod tracks with per-song BPM charts
- Easy / Normal / Hard
- Short and HOLD werewolf enemies
- Score / Combo / Accuracy / Defeated / Escaped / AGV Cleared
- Red AGV sweep every 50 points
- Deferred Results restart (RESTARTING → COUNTDOWN → PLAYING)
- Offline Windows onedir build
- Silent-mode fallback
