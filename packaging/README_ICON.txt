# macOS icon

No authorized dedicated `assets/art/icon.png` is present in this public
repository yet.

`build_macos.sh` will build `packaging/WerewolfRhythmDemo.icns` automatically
when an authorized `assets/art/icon.png` (or `packaging/icon.png`) is added.

Until then, the macOS `.app` uses the default system application icon.
Do not substitute private photographs or unrelated images.
