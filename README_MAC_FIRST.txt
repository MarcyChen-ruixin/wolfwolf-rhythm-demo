Werewolf Rhythm Demo v0.1.0-demo

1. Choose the build matching your Mac:
   - Apple Silicon (M1 / M2 / M3 / M4 and later)
   - Intel
2. Extract the ZIP.
3. Open Werewolf Rhythm Demo.app.
4. No Python installation is required.
5. The game works offline.
6. Controls use DFJK for the four lanes.
7. The build is currently ad-hoc signed and not notarized.
8. Download only from the official GitHub repository.
9. Do not disable macOS security protections.
10. Use Privacy & Security -> Open Anyway only after verifying the source.

Optional: drag Werewolf Rhythm Demo.app into Applications. Keep the
application bundle intact — do not remove files from inside the .app.
